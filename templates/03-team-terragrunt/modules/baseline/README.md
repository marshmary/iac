# baseline

Convention module shared by every component in this repo: it renders the
naming prefix (`<project>-<environment>`) and the identity tags that all
other modules are expected to accept. Deliberately provider-free — it
validates, plans, applies and tests fully offline on any cloud.

Terragrunt consumes it from `envs/<env>/baseline` via the unit's
`terraform.source`; see the unit's `terragrunt.hcl` for the wiring.

## Example

```hcl
module "baseline" {
  source      = "../.."
  project     = "my-app"
  environment = "dev"
}
```
