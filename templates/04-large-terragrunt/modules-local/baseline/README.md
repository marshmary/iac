# baseline (modules-local)

The default module every component in this repo starts from: it renders the
naming prefix (`<project>-<environment>`) and the identity tags that all
other modules are expected to accept. Deliberately provider-free — it
validates, plans, applies and tests fully offline on any cloud. It mirrors
tier 03's `modules/baseline` so the growth path between tiers stays smooth.

This tree is the FIRST-RUN fallback so `task plan` works out of the box
without a module registry. Two supported paths:

- **keep vendoring** (this tree): treat it as reviewed code — PRs, tests, no
  git-ignoring. Grow real modules beside it (`modules-local/<name>`);
- **move to a registry**: push `modules-local/*` into your `iac-modules`
  repo, pin tags, and flip each unit's `terraform.source` to the registry
  form (commented in every unit's `terragrunt.hcl`).

Terragrunt consumes it from `platforms/<cloud>/envs/<env>/<component>` via
the unit's `terraform.source`.

## Example

```hcl
module "baseline" {
  source      = "../.."
  project     = "my-app"
  environment = "dev"
}
```
